# PhonePe Trading system LLD

### Features implemented
- A registered user can place, modify, and cancel his/her orders.
- Concurrent order placement, modification, cancellation, and execution handled appropriately.
- An order book per symbol is maintained by the system

### Prerequisite (Packages to install)
- Python 3
- Pytest


### Running the application code
- Navigate to the root of the dir
- python main.py

### Running the tests
- Navigate to the root of the dir
- Run pytest test.py
